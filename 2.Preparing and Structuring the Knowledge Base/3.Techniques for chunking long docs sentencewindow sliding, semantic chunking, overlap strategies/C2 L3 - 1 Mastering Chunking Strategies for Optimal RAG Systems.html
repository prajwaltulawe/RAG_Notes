Complete Chunking Guide for RAG: Strategies, Implementations, and Best Practices
Retrieval-Augmented Generation (RAG) has revolutionized how we build AI applications, enabling language models to dynamically access external knowledge. At the heart of any efficient RAG system is chunking—the process of breaking documents into smaller, manageable pieces.
Chunking quality directly impacts:
•
Retrieval relevance: Well-structured chunks return more precise context.
•
System performance: Optimized sizes improve speed and reduce costs.
•
Response quality: Coherent context generates more accurate responses.
•
User experience: Fast, relevant responses increase satisfaction.

1. Fixed-Size Chunking (Fixed-Size Chunking)
Concept
The simplest and most straightforward method: divides text into fixed-size pieces (characters or tokens), with optional overlap to maintain context between adjacent chunks.
When to Use
✅ Uniform documents (articles, blog posts, simple documentation). ✅ Rapid RAG system prototyping. ✅ When document structure isn’t critical. ✅ Text without special formatting or hierarchy. ✅ Need for predictable chunk sizes.
Full Implementation

2. Semantic Chunking (Semantic Chunking)
Concept
Divides text based on semantic similarity, grouping sentences that cover the same topic. Uses embeddings to identify natural topic changes, creating thematically coherent chunks.
When to Use
✅ Documents with multiple distinct topics. ✅ Educational or technical content with clear transitions. ✅ When semantic coherence is critical for understanding. ✅ Articles with variable structure but well-defined topics. ✅ Need for thematically consistent chunks.
Full Implementation
from langchain_experimental.text_splitter import SemanticChunker from langchain_openai import OpenAIEmbeddings from typing import List, Dict import numpy as np import re class CustomSemanticChunker: """ Custom semantic chunking implementation with fine-grained control """ def __init__( self,
embeddings_model, similarity_threshold: float = 0.7, min_chunk_size: int = 100, max_chunk_size: int = 2000 ): """ Args: embeddings_model: Model to generate embeddings similarity_threshold: Threshold to consider sentences similar (0-1) min_chunk_size: Minimum chunk size in characters max_chunk_size: Maximum chunk size in characters """ self.embeddings = embeddings_model self.similarity_threshold = similarity_threshold self.min_chunk_size = min_chunk_size self.max_chunk_size = max_chunk_size def split_into_sentences(self, text: str) -> List[str]: """Split text into sentences""" sentences = re.split(r'(?&lt;=[.!?])\s+', text) return [s.strip() for s in sentences if s.strip()] def calculate_similarity(self, emb1: List[float], emb2: List[float]) -> float: """Calculate cosine similarity between two embeddings""" return np.dot(emb1, emb2) / (np.linalg.norm(emb1) * np.linalg.norm(emb2)) def chunk_text(self, text: str) -> List[Dict[str, any]]: """ Split text into semantic chunks Returns: List of dictionaries with 'text', 'start_index', 'end_index' """ sentences = self.split_into_sentences(text) if not sentences: return [] # Generate embeddings for all sentences sentence_embeddings = self.embeddings.embed_documents(sentences) chunks = [] current_chunk = [sentences[0]] current_embedding = sentence_embeddings[0] for i in range(1, len(sentences)): sentence = sentences[i] sentence_emb = sentence_embeddings[i] # Calculate similarity with current chunk similarity = self.calculate_similarity(current_embedding, sentence_emb) # Check current chunk size current_size = sum(len(s) for s in current_chunk) # Decide whether to add to current chunk or create new one if (similarity >= self.similarity_threshold and current_size + len(sentence) &lt;= self.max_chunk_size): # Add to current chunk current_chunk.append(sentence) # Update average embedding of chunk current_embedding = np.mean( [current_embedding, sentence_emb], axis=0 ) else: # Save current chunk if it meets minimum size chunk_text = ' '.join(current_chunk) if len(chunk_text) >= self.min_chunk_size: chunks.append({ 'text': chunk_text, 'sentence_count': len(current_chunk), 'avg_similarity': similarity }) # Start new chunk current_chunk = [sentence] current_embedding = sentence_emb # Add last chunk if current_chunk: chunk_text = ' '.join(current_chunk) if len(chunk_text) >= self.min_chunk_size: chunks.append({ 'text': chunk_text, 'sentence_count': len(current_chunk), 'avg_similarity': 1.0 }) return chunks # Method 1: Using LangChain SemanticChunker def semantic_chunking_langchain(text: str, breakpoint_type: str = "percentile"): """ Semantic chunking using LangChain implementation Args: text: Text to split breakpoint_type: 'percentile', 'standard_deviation', 'interquartile', 'gradient' """ text_splitter = SemanticChunker( OpenAIEmbeddings(), breakpoint_threshold_type=breakpoint_type, ) chunks = text_splitter.create_documents([text]) return chunks # Method 2: Custom implementation def semantic_chunking_custom( text: str, similarity_threshold: float = 0.75, min_chunk_size: int = 150, max_chunk_size: int = 1500 ): """ Semantic chunking with fine control """ embeddings = OpenAIEmbeddings(model="text-embedding-3-small") chunker = CustomSemanticChunker( embeddings_model=embeddings, similarity_threshold=similarity_threshold, min_chunk_size=min_chunk_size, max_chunk_size=max_chunk_size ) chunks = chunker.chunk_text(text) return chunks # Practical example sample_text = """ Artificial intelligence is revolutionizing the healthcare sector. Machine learning algorithms can diagnose diseases with impressive accuracy. Hospitals are implementing AI systems for medical image analysis. In the financial sector, AI is transforming how institutions operate. Real-time fraud detection protects millions of daily transactions. Automated trading algorithms process market information in milliseconds. Education is also being impacted by the technology. Adaptive learning platforms personalize teaching for each student. Teachers can use AI tools to identify students who need additional support. """ # Process chunks_custom = semantic_chunking_custom( sample_text, similarity_threshold=0.7, min_chunk_size=100, max_chunk_size=1000 ) print("=== Semantic Chunking ===") for i, chunk in enumerate(chunks_custom): print(f" Chunk {i+1}: {chunk['sentence_count']} sentences") print(f"Average similarity: {chunk['avg_similarity']:.2f}") print(chunk['text'][:150] + "...")

3. Document Structure-Based Chunking
Concept
Respects the document’s hierarchical structure (chapters, sections, paragraphs), preserving the original content’s logical organization and hierarchical context.
When to Use
✅ Technical documentation with clearly defined sections. ✅ Structured manuals and guides with hierarchy. ✅ Academic articles with standard formatting. ✅ Markdown, HTML, or LaTeX documents. ✅ Any content where structure is meaningful.
Complete Implementation
from langchain.text_splitter import MarkdownHeaderTextSplitter, HTMLHeaderTextSplitter
from langchain.schema import Document from typing import List, Dict, Tuple import re class StructuredDocumentChunker: """ Chunker that respects document structure Supports Markdown, HTML, and custom structured text """ def __init__(self, preserve_hierarchy: bool = True): """ Args: preserve_hierarchy: If True, includes context from parent sections """ self.preserve_hierarchy = preserve_hierarchy def chunk_markdown( self, markdown_text: str, headers_to_split_on: List[Tuple[str, str]] = None ) -> List[Document]: """ Splits Markdown document by headers """ if headers_to_split_on is None: headers_to_split_on = [ ("#", "Header 1"), ("##", "Header 2"), ("###", "Header 3"), ] markdown_splitter = MarkdownHeaderTextSplitter( headers_to_split_on=headers_to_split_on, strip_headers=False ) splits = markdown_splitter.split_text(markdown_text) if self.preserve_hierarchy: for doc in splits: hierarchy = [] for header_level, header_name in headers_to_split_on: if header_name in doc.metadata: hierarchy.append(f"{doc.metadata[header_name]}") doc.metadata['hierarchy'] = ' > '.join(hierarchy) return splits # Example: Markdown Chunking markdown_doc = """ # Introduction to Machine Learning Machine Learning is a subfield of artificial intelligence. ## Types of Learning There are three main types of learning in ML. ### Supervised Learning The model learns from labeled data. #### Classification Assigns categories to data. ### Unsupervised Learning The model finds patterns in unlabeled data. """ chunker = StructuredDocumentChunker(preserve_hierarchy=True) chunks = chunker.chunk_markdown(markdown_doc) for i, chunk in enumerate(chunks): print(f" Chunk {i+1}:") print(f"Hierarchy: {chunk.metadata.get('hierarchy', 'N/A')}") print(f"Content: {chunk.page_content[:100]}...")
4. Recursive Chunking (Chunking Recursivo)
Concept
Recursively splits text using a hierarchy of separators, trying to keep semantic units intact (paragraphs → sentences → words → characters).
When to Use
✅ General use - most versatile method. ✅ Texts with variable structure. ✅ When there are no explicit markers. ✅ Need for balanced chunks. ✅ Combination of code and text.
Complete Implementation
from langchain.text_splitter import RecursiveCharacterTextSplitter import tiktoken class AdvancedRecursiveChunker: """ Advanced recursive chunking implementation with token control """ def __init__( self, chunk_size: int = 1000, chunk_overlap: int = 200, length_function: str = "characters", model_name: str = "gpt-4", custom_separators: List[str] = None ): self.chunk_size = chunk_size self.chunk_overlap = chunk_overlap # Default separators (priority order) if custom_separators is None: self.separators = [ " ", # Multiple breaks " ", # Paragraphs " ", # Lines ". ", # Sentences " ", # Words "", # Characters ] else: self.separators = custom_separators # Setup counting if length_function == "tokens": self.tokenizer = tiktoken.encoding_for_model(model_name) self.length_func = lambda text: len(self.tokenizer.encode(text)) else: self.length_func = len def split_text(self, text: str) -> List[str]: """Recursively splits text""" text_splitter = RecursiveCharacterTextSplitter( chunk_size=self.chunk_size, chunk_overlap=self.chunk_overlap, length_function=self.length_func, separators=self.separators, ) return text_splitter.split_text(text) # Example: Custom separators for Python code code_separators = [ " class ", # Classes " def ", # Functions " ", # Blocks " ", # Lines " ", "", ] code_chunker = AdvancedRecursiveChunker( chunk_size=400, chunk_overlap=50, custom_separators=code_separators )
5. Context-Aware Chunking (Parent-Child)
Concept
Maintains relationship between “parent” chunks (larger context) and “child” chunks (specific excerpts). Enables granular search while keeping broader context available.
Complete Implementation
from langchain.retrievers import ParentDocumentRetriever from langchain.storage import InMemoryStore class ParentChildChunker: """ Parent-Child chunking strategy implementation """ def __init__( self, parent_chunk_size: int = 2000, child_chunk_size: int = 400, chunk_overlap: int = 50 ): self.parent_splitter = RecursiveCharacterTextSplitter( chunk_size=parent_chunk_size, chunk_overlap=chunk_overlap ) self.child_splitter = RecursiveCharacterTextSplitter( chunk_size=child_chunk_size, chunk_overlap=chunk_overlap ) def setup_retriever(self, documents: List[Document], collection_name: str): """Sets up retriever with parent-child strategy""" parent_store = InMemoryStore() # Vectorstore for child chunks vectorstore = Qdrant( client=qdrant_client, collection_name=collection_name, embeddings=OpenAIEmbeddings(), ) # Setup retriever retriever = ParentDocumentRetriever( vectorstore=vectorstore, docstore=parent_store, child_splitter=self.child_splitter, parent_splitter=self.parent_splitter, ) retriever.add_documents(documents) return retriever # Usage example documents = [Document(page_content="Your long document here...")] chunker = ParentChildChunker(parent_chunk_size=1500, child_chunk_size=300) retriever = chunker.setup_retriever(documents, "parent_child_collection") # Search - automatically returns parent context results = retriever.get_relevant_documents("your query")

Complete RAG System with LangGraph
Now let’s integrate everything into a production-ready RAG system:
from langgraph.graph import StateGraph, END from typing import TypedDict from langchain_openai import ChatOpenAI class RAGState(TypedDict): query: str documents: List[Document] retrieved_chunks: List[Document] answer: str chunking_strategy: str class AdvancedRAGSystem: """Complete RAG system with LangGraph""" def __init__(self): self.llm = ChatOpenAI(model="gpt-4", temperature=0) self.embeddings = OpenAIEmbeddings() self.graph = self._create_graph() def _create_graph(self): workflow = StateGraph(RAGState) # Add nodes workflow.add_node("analyze_query", self._analyze_query) workflow.add_node("choose_strategy", self._choose_strategy) workflow.add_node("chunk_documents", self._chunk_documents) workflow.add_node("retrieve", self._retrieve) workflow.add_node("generate_answer", self._generate_answer) # Define flow workflow.set_entry_point("analyze_query") workflow.add_edge("analyze_query", "choose_strategy") workflow.add_edge("choose_strategy", "chunk_documents") workflow.add_edge("chunk_documents", "retrieve") workflow.add_edge("retrieve", "generate_answer") workflow.add_edge("generate_answer", END) return workflow.compile() def _analyze_query(self, state: RAGState) -> RAGState: """Analyzes the query""" query = state['query'] state['metadata'] = { 'is_technical': 'implement' in query.lower(), 'needs_context': 'explain' in query.lower() } return state def _choose_strategy(self, state: RAGState) -> RAGState: """Chooses chunking strategy""" if state['metadata']['is_technical']: state['chunking_strategy'] = 'structural' elif state['metadata']['needs_context']: state['chunking_strategy'] = 'semantic' else: state['chunking_strategy'] = 'recursive' return state def _chunk_documents(self, state: RAGState) -> RAGState: """Splits documents""" # Implement chunking based on chosen strategy return state def _retrieve(self, state: RAGState) -> RAGState: """Retrieves relevant chunks""" # Search in vectorstore return state def _generate_answer(self, state: RAGState) -> RAGState: """Generates final answer""" # Use LLM with retrieved context return state def process(self, query: str, documents: List[Document]) -> dict: """Processes complete query""" initial_state = { 'query': query, 'documents': documents, 'retrieved_chunks': [], 'answer': '', 'chunking_strategy': '' } return self.graph.invoke(initial_state) # Usage rag = AdvancedRAGSystem() result = rag.process("How to implement async in Python?", documents) print(result['answer'])

Best Practices and Optimizations
1.
Strategy Selection
def choose_strategy(document: str, objective: str) -> str: """Guide for strategy selection""" if "```" in document or "class " in document: return "recursive with code separators" elif "# " in document or "" in document: return "structural to preserve hierarchy" elif len(document) > 10000 and objective == "precision": return "semantic for thematic coherence" elif objective == "broad_context": return "parent-child to expand when necessary" elif objective == "maximum_quality": return "agentic with enrichment" else: return "recursive (versatile and efficient)"
