What Makes a Token Embedding Meaningful?
How vectors give words meaning, and why direction is everything.
Words as Vectors: The Magic Behind Language Models
Every time you type a word into ChatGPT or translate a phrase with Google, you’re activating a mathematical object that looks nothing like language: a high-dimensional vector.
These vectors live in something called embedding space. There, the word “king” isn’t just a word: it’s a point in space, and relationships like:
"king" - "man" + "woman" ≈ "queen"
are not magic: they’re linear algebra.
Visual : Words in Space
What’s Inside an Embedding?
Formally, an embedding is a vector: e ∈ ℝᵈ, where d might be 50, 300, or even 768 (for BERT).
Each dimension is not a direct human concept (like “royalty” or “femininity”), but the combination of them is interpretable through behavior.
We don’t know the axes, but we know the geometry matters.
Similarity Is Direction, Not Distance
When two words are “similar”, what we really mean is that their angle is small. We measure this using cosine similarity:
cos(θ) = (e₁ ⋅ e₂) / (|| e₁||·||e₂||)
Why not just use Euclidean distance? Because the magnitude of embeddings varies, but we care more about semantic alignment.

How Do Embeddings Learn Meaning?
Let’s start simple.
➤ Word2Vec:
Predicts surrounding context words from a given center word (Skip-Gram), or vice versa (CBOW).
This forces the model to group words used in similar contexts near each other.
Loss Function:
L = −log σ(vᵒ · vᶜ) − ∑ log σ(−vⁿ · vᶜ) where vᵒ is the output word vector, vᶜ is the center word vector, and vⁿ are negative samples.
Visual : Skip-Gram Architecture - Word2Vec
➤ BERT:
Contextual embeddings: meaning each token’s vector depends on the full sentence.
“Bank” in
•
“river bank”
•
“bank loan” has different embeddings.
This is done via Transformer attention and masked token prediction.

Embeddings and Geometry: What’s Meaningful?
Let’s unpack what structure emerges in embedding space:
•
Clustering: Synonyms like “happy”, “joyful”, “cheerful” group together
•
Linear Analogies: “king - man + woman ≈ queen”
•
Semantic Axes: Gender, plural/singular, tense become linear subspaces
Visual : Semantic Axes - Gender / Plurality
PCA and UMAP: How We See the Unseeable
Embeddings live in 300–1000 dimensions. But we often project them down to 2D using:
•
PCA (Principal Component Analysis): Preserves variance
•
UMAP (Uniform Manifold Approximation): Preserves local structure

Satyam’s Explanation
Imagine every word is a dot on a paper. Some dots are near each other: “apple”, “banana”, “mango”. Some are far: like “war” and “dessert”.
When a model learns these dots, it’s like learning how close words live in a giant neighborhood.
You can go from “cat” to “dog” in a short walk, but getting to “philosophy” is a long drive.
