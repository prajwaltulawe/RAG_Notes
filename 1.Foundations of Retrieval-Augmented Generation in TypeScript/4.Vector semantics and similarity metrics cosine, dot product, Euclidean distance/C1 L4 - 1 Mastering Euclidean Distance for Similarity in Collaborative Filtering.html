Calculating the Euclidean Distance for a Collaborative Filtering-Based Recommendation System
Hello, let’s continue our posts about Recommendation Systems in Python.
There are several approaches to developing such a system, but the one I’ll use is one that was already used by Netflix and is still used by some platforms.
To learn more about how it works and the various approaches, I recommend reading my other post at this link: How a recommendation system works.
The Data
So let’s get started. The first thing we’ll need is data, of course—without it, there’s no analysis or recommendations. Data can be obtained from n sources and n ways, but we’ll simplify with a simple JSON format dataset, which is very commonly used. See the structure:
avaliacoes = {'Carry a estranha':
{'Luiza': 2.5,
'Marcos': 3.0 ,
'Felipe': 2.5,
'Vanessa': 3.0,
'Janaina': 3.0,
'Julio': 4.0},
We have a variable named avaliacoes and several movies with ratings from 0 to 5.
Importing the Necessary Libraries
Now let’s transform it into a Pandas DataFrame to make the processes easier. Import pandas and the sqrt function from the math library—you’ll see where and how they’re used below.
# Imports
import pandas as pd
from math import sqrt
# JSON to DataFrame
df = pd.DataFrame(avaliacoes)
We’ve transformed the JSON data into a DataFrame; notice it looks similar to an Excel table.
Notice there are also missing data (NaN), which indicate that the user hasn’t seen the movie. This isn’t a problem, just like in other data analysis projects. It’s natural that users haven’t consumed various titles, and that’s exactly what we want our system to do.
Calculating Similarity Between Users
The “mathemagical” part behind the scenes of the system is calculating the similarity between various or all items using Euclidean distance. Let’s see how it works:
Carrie a estranha (Luiza) = 2.5 and Star Trek (Luiza) = 3.0. Subtract the 2 ratings, see the code:
#1. We choose 2 movies and subtract the ratings from each user who saw them n1 = 2.5 n2 = 3.0 sub = n1 - n2
See that the result is 0.5. We have the difference between the 2 ratings. When rating 1 is less than rating 2, the result will be negative and could cause issues. To fix this, we’ll use a Python function, abs(), which makes the result always positive.
sub = abs(n1 - n2)
There we go—now regardless of the values, the result will be positive. The next step is to do the same operation with another user; let’s pick Vanessa, since she watched both movies.
sub = abs(3 - 1.5)
The result is 1.5. For now, these numbers don’t make much sense, but keep going—the “magic” will happen.
Now let’s add the two results:
soma = 0.5 + 1.5
The total is 2. Let’s calculate the square root of that value. It’s possible to do it without a library, but we’ll import the sqrt function from the Math library.
from math import sqrt raiz = sqrt(2)
The result is 1.41. This number, believe it or not, is the Euclidean distance between the two movies. The smaller it is, the more similar the movies are.
Percentage Format (Between 0 and 1 or 0 and 100)
Just divide 1 by the square root result + 1:
similaridade = 1/(1.41)
The result is 0.41, meaning 41% similar—multiply by 100 and you get that result. Easy, right?
Carrie a estranha and Star Trek have 41% similarity. Notice that the smaller the distance number, the higher the percentage.
Controversy
So you might ask: Wait, but Carrie a estranha has nothing to do with Star Trek. Exactly—understand that we’re working with data, and you already know that to get relevant results, we need what? Data, of course—lots of high-quality data. We’re using just 2 simple records from a tiny database as an example. The fact that a user who likes sci-fi enjoyed a horror movie once doesn’t mean they like others. That’s why a data-based system needs to be carefully thought out and developed before going into production. Got it? So let’s continue.
Automating the Process
The next step is to do this manual calculation for all the other data in that notebook you don’t even use anymore lol. Of course not—in college, not long ago, we had to write code in notebooks before going to the machine :| . That’s why we have programming languages, and among them, Python for our delight. Shall we automate the process?
To do this, we’ll create a function named similaridade with the following code:
def similaridade(fil1, fil2): #Verifica os filmes vistos pelos 2 usuários lista = [item for item in avaliacoes[fil1] if item in avaliacoes[fil2]]
#Calcula a similaridade se o filme for comum if len(lista) != 0: return 100 * (1/(1+sum([abs(avaliacoes[fil1][item] - avaliacoes[fil2][item]) for item in lista])))
Testing
similaridade(‘Carrie a estranha’, ‘Star Trek’)
The result is 25%.
It looks confusing, but it’s straightforward—we’re using list comprehensions, which greatly reduce the code and are very performant.
In the line: lista = [item for item in avaliacoes[fil1] if item in avaliacoes[fil2]]
The code in brackets generates a list of all users who saw both movies: [‘Luiza’, ‘Vanessa’, ‘Julio’]. To see it, just add a print(lista) below the line.
The next code does look more complicated—at first I thought so too—but breaking it down and practicing makes it simple.
The if len(lista) != 0: checks the list length; if it’s not zero, we proceed; otherwise, the function stops since there’s no data to calculate.
Now the beast:
return 100 * (1/(1+sum([abs(avaliacoes[fil1][item] - avaliacoes[fil2][item]) for item in lista])))
It simply does the same calculations we did at the beginning, but automated and compact. Let’s break it down for clarity.
100 * : Multiplies the result by 100 to get a percentage between 0 and 100.
1/: Divides 1 by the result to get a value between 0 and 1.
1+: To avoid division by zero issues.
sum([abs(avaliacoes[fil1][item] - avaliacoes[fil2][item]) for item in lista])))
Subtracts the ratings of movie 1 from movie 2 for each user pair in the list, applies abs, and sums all values. The list items before summing are [0.5, 1.5, 1.0].
