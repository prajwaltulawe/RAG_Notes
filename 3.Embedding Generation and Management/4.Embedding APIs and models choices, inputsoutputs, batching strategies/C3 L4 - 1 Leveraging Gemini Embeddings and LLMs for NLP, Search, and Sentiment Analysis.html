Gen AI Capabilities - Use Case 1 - Embeddings for Contextual Understanding
Contextual word understanding is vital for NLP tasks, requires costly embeddings, either trained on vast domain datasets or using pre-trained embedding models, both computationally intensive.
Developing and maintaining domain-specific text embeddings demands substantial computational resources and continuous effort.
Objective
For NLP tasks listed below, in any domain
· Task 1 - For a given word, find top N similar words from list of words.
· Task 2 - Similarity between two words
· Task 3 - Detect the ‘odd’ word from list of words.
Embeddings
· Gensim can be used for training custom word embeddings (Word2Vec, FastText).
· Pre-trained GloVe embeddings offer a time-saving alternative, already trained on large datasets.
· GloVe embeddings come in varying dimensions (e.g., 50, 100, 200, 300), with higher dimensions capturing more detail but increasing computational cost.
The LLM Paradigm: Re-evaluating Embedding Strategies in NLP
The emergence of Large Language Models (LLMs) represents a significant paradigm shift in Natural Language Processing (NLP). Their inherent capacity for cross-domain contextual understanding suggests a future where the necessity for bespoke embedding generation is substantially reduced, offering a pre-existing semantic substrate that accelerates development cycles and minimizes computational overhead.
However, two critical considerations remain:
•
Domain-Specific Adaptation: While LLMs provide robust general contextual representations, fine-tuning these representations on domain-specific corpora is often essential for achieving optimal performance in specialized NLP applications.
•
Contextual Dependency Management: Ongoing research into expanding context window sizes and developing efficient methods for handling long-range dependencies is paramount to fully realize the potential of LLMs in complex NLP tasks involving extensive textual contexts.

def embedding_task(text,task,target=''): response = client.models.embed_content( model='models/text-embedding-004', contents=text,config=types.EmbedContentConfig(task_type='semantic_similarity')) df=pd.DataFrame([e.values for e in response.embeddings ], index=text) sim=df @ df.T #Similarity Score if task == 'similarity': score = round(sim.loc[text[0], text[1]], 2) print(f"Similarity Score between '{text[0]}' and '{text[1]}' (embedding dimension: {df.shape[1]}): {score}") # Top 3 semantically similar words elif task == 3: if target not in sim.index: print(f"Target word '{target}' not found in the embedding index.") return [] topn = sim.sort_values(by=target, ascending=False)[target] topn_indices = topn.index[1:task+1] top_similar_words = list(topn_indices) print(f"Top {task} similar words to '{target}' (embedding dimension: {df.shape[1]}): {top_similar_words}") # Semantically similar words have close embeddings in high-dimensional space. The odd word's embedding will have the lowest average cosine similarity to others, indicating dissimilarity. elif task=='odd': print("From the list:",text) # Calculate the average similarity of each word to all other words average_similarities = np.sum(sim, axis=1) / (len(text) - 1) # The word with the lowest average similarity is likely the odd one out odd_word_index = np.argmin(average_similarities) odd_word = text[odd_word_index] print(f"Embedding dimension: {df.shape[1]}") print(f"The odd word is: {odd_word}")
