Namespaces in TypeScript
You might have come across the term ‘namespace’ while working with TypeScript. And you might wonder what on earth a namespace is? We’ll cover the basic concepts of namespaces and how we can use them to write efficient code.
Namespace is a context for identifiers, a logical grouping of names used in a program.
This definition from MDN Web Docs is a great explanation of namespaces. We should know that namespace is not an exclusive concept of TypeScript. Languages like C++ and Python also have namespaces. However, in this article, we’ll be covering namespaces with TypeScript in mind.
Prerequisites
This post assumes you know the basics of TypeScript. Small explanations of what our code does are provided, but no in-depth elaboration.
It will also be helpful if you have Node.js and TypeScript already installed. You can try the online TypeScript Playground. But executing TypeScript with Node.js is preferred.
You can refer to a previous article, First Step towards TypeScript, to learn how to get started with TypeScript.
Declaring a Namespace
The keyword to declare a namespace is, well, “namespace”. The syntax is as follows:
namespace { // namespace members go here }
We’ll declare a namespace with the identifier “DigitsInNumber” and define some functions that we’ll use in a separate file.
Let’s break the code down into simpler steps.
Step 1: We declare a namespace named “DigitsInNumber”. We want to use this namespace in another file, so we’ll export it using the export keyword.
Step 2: We define a function isNumber() which accepts a parameter named value. We won’t use this function directly anywhere else outside the file, so we won’t export it. We’re just returning the negated value of isNaN() with the parameter value.
If value is not a number, isNaN(value) will return true. Negating this results in false. So our isNumber() function takes a value, checks if it’s a number using the built-in isNaN() function, and returns a boolean result accordingly.
Step 3: We now define a function to count the number of digits, which we’ll need in an external file, so we use export to export the countDigits() function.
We’ll call our isNumber() function to check if the value is a number. Then we’ll check if it has one, two, or more than two digits. For simplicity, we’ll ignore all negative numbers. An appropriate string is returned based on the conditional logic outcome.
Importing and Using our Namespace
Now that our namespace is ready, let’s use it! For this, we’ll create a separate file “countDigitsDriver.ts” to run our code.
We import namespaces as:
import {} from "location"
So we do import {DigitsInNumber} from “./digitsInNumber.ts” to import our namespace. Note that only exported members of a namespace can be used in external files. So while we can use the countDigits() function here, we won’t be able to access the isNumber() function since it’s not exported.
The syntax to use a member of a namespace is:
nameSpaceName.functionName()
We call our DigitsInNumber.countDigits() function with different parameters and use console.log() to print the outputs. Now it’s time to see our code in action.
Compiling and Execution
We’ll ask the TypeScript compiler to compile our TypeScript code into JavaScript so we can run it with Node.js. We’ll use the command tsc digitsInNumber.ts countDigitsDriver.ts to compile the code. Then we’ll execute it with node countDigitsDriver.ts.
If everything went well, we should see our expected output.
Conclusion
We’ve successfully defined, exported, and used a namespace. We learned how to export only selected members of a namespace and how to use namespace members properly.
